# 🦷 Dental Appointment System with Email Notifications

A **responsive web application** for booking and managing dental appointments. Patients can register, book appointments, and receive **automated email confirmations**. Admins can manage appointments, services, and patient records through a secure dashboard.

## 📌 Overview

This system helps streamline the dental appointment process with email notifications. Patients can register, log in, select services, and book available time slots. Admins have full control over managing appointments, services, and users through an intuitive dashboard.

---

## ✨ Features

### 👤 Patient Side

- ✅ User registration with **email OTP verification**
- 🔐 Login using **token-based authentication**
- 🦷 Browse and select **available dental services**
- 📅 Book appointments by selecting **date and time**
- 📧 Receive **confirmation emails** after booking

### 🔧 Admin Side

- 📊 Admin dashboard with real-time **statistics**
- 👁️ View, confirm, or cancel **appointments**
- ➕ Add or update **dental services**
- 📁 Manage **patient records**

---

## 🛠️ Tech Stack

### Frontend
- HTML, CSS, Bootstrap
- JavaScript

### Backend
- Node.js with Express.js
- Supabase (Database & Authentication)
- Nodemailer (Email Notifications)
