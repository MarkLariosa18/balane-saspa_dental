Dental Appointment System with Email Notifications ==================================================
 A responsive web application for booking and managing dental appointments. Patients can register, book appointments, and receive email confirmations. Admins can manage appointments, services, and patient records through a secure dashboard. Table of Contents -----------------

-----------Overview -------- 
This system helps streamline the dental appointment process with automated email notifications. Patients can register, log in, select services, and book available time slots. Admins have full control over appointments, services offered, and user management. Features -------- Patient Side: - User registration with email OTP verification - Login with Token-based authentication - Browse and select dental services - Book appointments by selecting date and time - Receive confirmation emails after booking 
--------Admin Side: - Dashboard with statistics - View, confirm, or cancel appointments - Add or update dental services - Manage patient records 
--------Tech Stack ----------
 Frontend: - HTML, CSS, Bootstrap - JavaScript Backend: - Node.js with Express.js - Supabase  - Nodemailer notifications
